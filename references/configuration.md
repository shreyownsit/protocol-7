# Backend Configuration

**Requirement:** All configuration flows through a single typed settings object loaded from environment variables. Secrets are never committed, never defaulted to production values, and never logged.

**Why:** Single source of truth prevents config drift between the API container, the worker container, and migrations runner, all of which import `app.core.config.Settings`.

## 1. Settings Object

`app/core/config.py` — one `Settings(BaseSettings)` class, all fields required unless a dev-only default is stated:

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8")
```

## 3. Environment Differences

| Aspect | dev | staging | prod |
|---|---|---|---|
| TLS | none (localhost) | required | required + HSTS |
| CORS | localhost:3000 | preview domains | production domain only |
| Secrets | scaffold-generated, gitignored `.env` | platform vault | platform vault (AWS Secrets Manager / Render env) |
| DB | local postgres via compose | managed, small tier | managed, HA tier, PITR |
| Storage | MinIO | R2/S3 | R2/S3 with lifecycle purge rules |
| Logging | console JSON | console JSON → log sink | console JSON → log sink + optional Sentry |
| Migrations | auto-run on boot | release step | release step (pre-deploy) |
| Debug endpoints | enabled (`/debug/` prefix, dev-only router guard) | disabled | disabled |

## 4. Rules

1. **No defaults for secrets.** Every secret variable raises at startup if unset in staging/prod.
2. `Settings` is constructed once in `app.core.config` and injected via FastAPI dependency; tests construct their own overrides.
3. Config values are never read inside `domain/` — domain receives values as function arguments (purity rule).
4. Feature flags beyond this registry require a root decision; do not add ad-hoc flags.
5. The dev scaffold script (`scripts/generate_dev_env.py`) generates `ENCRYPTION_KEY`, `SECRET_KEY`, `JWT_SECRET` and MinIO keys into `.env.dev`; this file is gitignored.

## Security

`ENCRYPTION_KEY` derivation and per-document key lifecycle: `file-storage.md`. `JWT_SECRET` rotation policy: `authentication.md`. Secret injection via platform vault only in staging/prod; no secrets on the command line or in image layers.

## Testing

A unit test asserts every prod-required variable raises when unset; a dev test asserts the scaffold produces a loadable `.env.dev`; an integration test asserts the API boots with only env overrides.
