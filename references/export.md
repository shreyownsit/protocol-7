# Export

**Requirement:** Export findings and counter-offers as PDF or DOCX: data → template renderer → document generation → temporary artifact storage → signed download URL. The export system must NOT expose arbitrary files from storage; signed, time-limited URLs only.

**Why:** Users need a shareable counter-offer document they can send to the other party. Export is a controlled snapshot of analysis results — never of raw contract binaries.

## 1. Architecture

```
Findings / counter-clause data (user-selected subset)
        ↓
  POST /api/v1/export   → Export row (queued) → enqueue export_generation
        ↓
  Template renderer (Jinja2 → HTML/LaTeX-like intermediate)
        ↓
  Document generation: PDF (weasyprint) | DOCX (python-docx)
        ↓
  Encrypt + store: sessions/{sid}/exports/{export_id}.{pdf|docx}  (TTL)
        ↓
  Signed GET URL (5 min) returned via polling /export/{id}
```

## 2. Endpoint

```
POST /api/v1/export
Auth: access; active owned session.
Request: {
  "session_id": "...",
  "format": "pdf" | "docx",                     // else EXPORT_TYPE_UNSUPPORTED
  "contents": {
    "counter_clauses": ["<counter_clause_id>..."],
    "findings": ["<finding_id>..."],            // optional subset; default all
    "include_summary": true,
    "include_risk_model": true
  }
}
Response 202: { "export_id": "...", "status": "queued" }

GET /api/v1/export/{export_id}
→ ready: { "url": "<signed>", "expires_at": "...", "filename": "lexiclear-counter-offer.pdf" }

GET /export-download/{export_id}?signature=...   (signed-URL target; validates signature +
                                                 expiry + path structure; 302 → storage)
```

The download path is the **only** URL that reaches object storage, and it is verified against the export row's `storage_key` — a crafted path → `EXPORT_URL_INVALID` (403).

## 3. Contents Selection and Validation

- `contents` is validated: ids must belong to the session; unknown ids → `details` list; empty selection → `VALIDATION_ERROR`.
- Export generation is idempotent on `(session_id, sha256(json(contents)))` — identical repeat requests return the existing export (if not expired).
- Counter-clauses included render with `counter_text` + `rationale` + compliance check summary (the auditor evidence digest, not raw rule internals).
- Findings render with severity, summary, statute reference, and a deep-link footnote (page number + clause heading) — the exported document keeps evidence links.

## 4. Template Rendering

- PDF: HTML template (Jinja2, styled for A4) → `weasyprint`. DOCX: `python-docx` builder (header, sections per finding, counter-clauses section, signature block placeholder).
- Templates live in `app/processing/export_templates/` (versioned directory). Template variables are strictly the serialized export payload — no request context leaks in.
- Pagination: PDF auto-paginated by weasyprint; a footer shows "Generated by LexiClear — analysis of {date}".

## 5. Export Celery Job (`workers/tasks/export.py`)

Timeout 5 min. Retries 2. On generation failure → `EXPORT_FAILED`, export row keeps `failed` status, frontend offers retry (re-enqueue is idempotent-safe). On success → artifact stored, URL signed, row `ready` + `url_expires_at`. Artifact TTL: `EXPORT_ARTIFACT_TTL_SECONDS` (default 24 h); after expiry the artifact is lifecycle-deleted and the row serves a re-generation affordance (`EXPORT_URL_EXPIRED`).

## 6. Failure Modes

`EXPORT_FAILED`, `EXPORT_TYPE_UNSUPPORTED` (422), `EXPORT_URL_EXPIRED` (410), `EXPORT_URL_INVALID` (403, also covers signature-tamper and path traversal), `VALIDATION_ERROR` (422).

## 7. Security

- **No arbitrary file exposure:** download path resolution is row-scoped; listing is bucket-disabled (`file-storage.md`); no endpoint accepts user-supplied storage keys.
- Exported documents contain only selected analysis results — never `source_text_raw` beyond ≤150-char evidence quotes (same evidence-length rule as negotiation).
- Filenames are server-generated (no user-controlled filename → no header injection).
- Rate limit: 10 exports/hour/session.

## Testing

Unit: contents validator (missing ids, cross-session ids, empty selection); template rendering with fixture payload (deterministic output hash per payload version). Integration: export job → artifact exists → signed URL downloads → checksum matches expected content composition test (findings + counter-clauses present, raw clause text absent); path-traversal attempt → `EXPORT_URL_INVALID`; idempotency (same contents twice → one artifact). Expiry test: frozen clock → expired URL rejected.
